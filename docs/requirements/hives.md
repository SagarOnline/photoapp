# HIve Requirements

## HIVE-001: Create a HIve

Status: Accepted  
Priority: Must  
Phase: MVP

A user must be able to create a named HIve for a shared event.

### Acceptance Criteria

- Creation completes in under 30 seconds.
- The HIve receives a unique invite code.
- The creator can see the HIve in the HIves dashboard.

## HIVE-002: Share a HIve

Status: Accepted  
Priority: Must  
Phase: MVP

A user should be able to share a HIve invite through a link or code, including WhatsApp.
