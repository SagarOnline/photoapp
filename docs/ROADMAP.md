# MVP Roadmap

## Phase 1

- Flutter setup.
- Supabase integration.
- Sign-up and sign-in (phone/email verification, Google and Apple sign-in).
- Theme.
- Routing.

## Phase 2

Hives.

Features:

- Create Hive.
- Join Hive.
- QR invite.
- Invite link.

## Phase 3

Gallery.

Features:

- Grid.
- Lazy loading.
- Full-screen preview.

## Phase 4

Uploads.

Features:

- Camera.
- Gallery picker.
- Compression.
- Progress indicator.

## Phase 5

Downloads.

Features:

- Save image.
- Download all (ZIP later).

## Future

- AI duplicate removal.
- AI highlights.
- Stories.
- Face recognition.
